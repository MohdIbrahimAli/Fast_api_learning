# Fast API learning
Here you can learn about the FastAPI from the very basics like initializing the FastAPI to  advanced concepts like user authentication using JWT tokens, user Association, Advanced validation and Error handling
<br/>
<br/>
To start you can clone the repo or fork it from the top right corner of this page
<br/> 
Run this command to clone the repo

``` bash
git clone https://github.com/MohdIbrahimAli/Fast_api_learning.git
cd Fast_api_learning
```
create a virtual environment for the development

``` bash
#windows
python -m venv .venv
.venv/scripts/activate
#mac
python3 -m venv .venv
source .venv/bin/activate
```
install the dependencies
``` bash
pip install -r requirements.txt
```
