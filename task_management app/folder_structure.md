In this step we will try to understand the standard level of folder structure which is used by senior developers of in an organisations. 
Here we will try to implement the functionality of a **Task Management** app 

**step 1:-**<br/>
Create a **.env** file to store all our external links or API's, port no for the backend server etc 

**step 2:-**<br/>
Create a **requirements.txt** file and **.gitignore** file

**step 3:-**<br/>
Create **main.py** or **app.py** this file will contain the main FastAPI aplication for us.

**step 4:-**<br/>
**Important** Create a python virtual environment and activate it
``` powershell    
#for windows
.venv/scripts/activate

#for MAC
source .venv/bin/activate
```
**step 5:-**<br/>
create **src** folder which holds all of our main functions and different components for the application
